## Create a New Project

Use our CLI to create a new SpinAI project:

```bash
npx create-spinai
```

## Development Container Setup

To streamline the development process, we've introduced a development container configuration. This setup requires Docker and Visual Studio Code with the Remote - Containers extension installed.

1. Open your project in Visual Studio Code.
2. Press `F1` to open the command palette and type "Remote-Containers: Open Folder in Container..." then hit enter.
3. Select your project folder. Visual Studio Code will build the container defined in `.devcontainer/devcontainer.json` and open your project inside it.

Your development container is now set up! This container includes all the necessary extensions and port forwards, and it automatically configures your environment variables.

## Choose a template, and configure your .env

Read the README of the template you chose for a full list of env variables to setup.

Usually, you'll need at minimum a `.env` file with your LLM's API key. All templates use OpenAI by default, but you can change the provider to your preferred LLM.

```bash
OPENAI_API_KEY=your_api_key_here
```

## Application Initialization

Before running your agent, ensure that all required environment variables are set. The application checks for these variables on startup:

- `AZURE_OPENAI_API_KEY`
- `AZURE_OPENAI_ENDPOINT`

Optionally, if you're using specific models or regions, also include:

- `AZURE_OPENAI_MODEL_NAME`
- `AZURE_OPENAI_REGION`

These checks are crucial for the application to run correctly and interact with the Azure OpenAI services.

## Run Your Agent

Start your agent with the following command. This will also perform a check for the necessary environment variables before initializing:

```bash
npm run dev
```

If any required environment variables are missing, the application will terminate, prompting you to set them.
