## Introduction

This documentation provides detailed information on the costs associated with using various versions of the GPT-4.1 models. Understanding these costs will help users manage their resources more effectively and make informed decisions when integrating these models into their applications.

## Cost Details for GPT-4.1 Models

The cost of using GPT-4.1 models is determined based on the number of tokens processed. This includes both the input tokens sent to the model and the output tokens generated by the model. Below are the costs per 1 million tokens for the standard, mini, and nano versions of the GPT-4.1 model.

### Standard GPT-4.1 Model

- **Input Cost:** $2.00 per 1M tokens
- **Output Cost:** $8.00 per 1M tokens

### GPT-4.1 Mini Model

- **Input Cost:** $0.40 per 1M tokens
- **Output Cost:** $1.60 per 1M tokens

### GPT-4.1 Nano Model

- **Input Cost:** $0.10 per 1M tokens
- **Output Cost:** $0.40 per 1M tokens

## Managing Costs with Different Models

Choosing the right model version can significantly impact the cost of your application. The standard GPT-4.1 model offers the most comprehensive capabilities but at a higher cost. The mini and nano versions provide more cost-effective solutions for applications that can sacrifice some level of capability or complexity in the generated output.

### Example Cost Calculations

To illustrate the cost implications of using different GPT-4.1 models, consider the following scenarios:

- **Scenario 1:** Processing 500,000 input tokens and generating 1,000,000 output tokens with the standard GPT-4.1 model.
- **Scenario 2:** Processing the same amount of tokens with the GPT-4.1 mini model.
- **Scenario 3:** Processing the same amount of tokens with the GPT-4.1 nano model.

```typescript
// Scenario 1: Standard GPT-4.1 Model
const inputCost = 500000 * (2.00 / 1000000);
const outputCost = 1000000 * (8.00 / 1000000);
const totalCost = inputCost + outputCost;
// Total Cost: $10.00

// Scenario 2: GPT-4.1 Mini Model
const inputCostMini = 500000 * (0.40 / 1000000);
const outputCostMini = 1000000 * (1.60 / 1000000);
const totalCostMini = inputCostMini + outputCostMini;
// Total Cost: $2.00

// Scenario 3: GPT-4.1 Nano Model
const inputCostNano = 500000 * (0.10 / 1000000);
const outputCostNano = 1000000 * (0.40 / 1000000);
const totalCostNano = inputCostNano + outputCostNano;
// Total Cost: $0.50
```

As demonstrated, the choice of model significantly affects the overall cost, with the nano model offering the most cost-effective solution for this scenario.

## FAQs

### How are tokens counted?

Tokens are pieces of words or punctuation, roughly corresponding to a word or part of a word. The exact count can vary based on the input language and the tokenization process.

### Can I switch between models to manage costs?

Yes, you can switch between different model versions depending on your application's needs and budget constraints. It's advisable to evaluate the performance and output quality of each model version to find the best fit for your use case.
